# Chain Rush 🍬

**Connect matching candies in a chain!** A hyper-casual puzzle game where you draw lines through same-color candies to score points and beat 300 levels.

---

## 🎮 Description

Draw a continuous line through moving candies of the same color. Chain 3+ candies = explosion + points. Reach the target score before the timer runs out!

- **300 levels** with a parametric difficulty curve
- **7 candy colors** + golden, rainbow and bomb specials
- Coins, shop with illustrated boosters
- 100% downloaded assets (candy pack + Kenney UI/audio), no code-generated art
- Vanilla JS, responsive on every screen, no black bars

---

## 🕹️ Controls

### 📱 Mobile (Touch)

| Gesture | Action |
|---|---|
| **Touch & drag** through same-color candies | Draw a chain to connect them |
| **Tap** the pause button ⏸ | Pause the game |

### 💻 Desktop (Mouse + Keyboard)

| Key / Gesture | Action |
|---|---|
| **Click + drag** through same-color candies | Draw a chain to connect them |
| **Esc** or **P** | Pause the game |
| **Enter** / **Space** | Confirm / Continue |

---

## 🎯 Gameplay

### How to score

- **Tap or drag** through 3+ candies of the **same color** in a line
- Longer chains = **bigger explosions** and **more points**
- **Golden candy** 🪙 = bonus coins when collected
- **Rainbow candy** 🌈 = matches any color
- **Bomb candy** 💣 = destroys surrounding candies

### Levels & Progression

- **300 levels** across multiple worlds
- Difficulty increases: faster candies, more colors, tighter time limits
- Earn coins to buy **boosters** in the shop

### Shop Boosters

| Item | Price | Effect |
|---|---|---|
| 🌈 Rainbow Pop | 200 | Clear one color instantly |
| ⭐ Star Rush | 300 | 2× score for 10 seconds |
| 💥 Big Blast | 400 | Blast the center of the board |
| ⏱ Sweet Time | 500 | +10 seconds on the timer |
