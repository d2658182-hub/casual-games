# 🎮 Casual Games Collection

Three hyper-casual web games built with vanilla JavaScript and Canvas 2D. No frameworks, no build steps — instant loading on any device.

| Game | Levels | Description |
|---|---|---|
| 🌸 **[Bloom Busters](bloom-busters/)** | 250 | Deduction puzzle — guess the secret matching rule in a magical garden |
| 🍬 **[Chain Rush](chain-rush/)** | 300 | Connect same-color candies in chains to score before time runs out |
| 🍭 **[Candy Rush](candy-rush/)** | 150 | Color-matching runner — move left/right, switch colors, collect sweets |

---

## Quick Start

Each game is a standalone folder. Open `index.html` directly or serve with:

```bash
cd bloom-busters && python3 -m http.server 8080
```

## Tech Stack

- **Vanilla JavaScript** (ES6+)
- **Canvas 2D** for rendering
- **No frameworks, no build tools**
- **100% downloaded assets** (CC0 / CC-BY)
- **Responsive** — works on mobile, tablet, and desktop
