# 🍭 Candy Rush

**Move the ball, match the gates, collect sweets!** A hyper-casual candy game with a Color Rush mechanic wrapped in a cute candy world — **150 levels across 10 themed worlds**.

---

## 🎮 Description

Pick the exact color with **4 round color buttons** (**pink → mint → sky → lemon**), move the ball **left / right** to collect sweets, pass the candy gates that match your color, chain combos and trigger **FEVER mode**. Complete objectives, earn **1-3 stars**, unlock new worlds, and collect coins to buy upgrades and cosmetic unlocks.

Built in **100% vanilla JavaScript** (no framework, no build step) — instant loading, works on every screen size.

---

## 🕹️ Controls

### 📱 Mobile (Touch)

| Gesture | Action |
|---|---|
| **◀ / ▶** buttons (bottom bar) | Move the ball left / right |
| **4 color buttons** (bottom bar) | Switch to pink, mint, sky, or lemon |
| **Tap** ⏸ (pause button) | Pause the game |

### 💻 Desktop (Keyboard)

| Key | Action |
|---|---|
| **←** / **→** arrow keys | Move the ball left / right |
| **1** – **4** number keys | Switch to color 1 (pink), 2 (mint), 3 (sky), 4 (lemon) |
| **Space** / **↑** / **Enter** | Cycle to next color |
| **Esc** | Pause the game |

## 🎯 Gameplay

### How to play

1. **Move** ◀ / ▶ to dodge obstacles and **collect sweets** (donuts, ice-creams, cookies…)
2. **Switch color** to match the upcoming gate — pass gates of the **same color** for points
3. **Mismatch** = lose a heart 💔
4. Switch color **at the last moment** for a **PERFECT** bonus ✨
5. Chain combos → **FEVER mode** at ×5 combo (double points, glow, music speeds up 🔥)
6. Complete each level's **objective** to win stars and unlock the next level

### Objectives

- 🎯 **SCORE** — reach the target score
- 🍬 **CANDIES** — collect N sweets
- ⏱ **SURVIVE** — pass every gate without losing all hearts

### On Game Over

- **REVIVE** — come back exactly where you died
- **RETRY** — restart the same level

### On Victory

- **NEXT** — proceed to the next level
- **BONUS** — double your earned coins
